# Vinayak Gavimath — GTM Engineering Portfolio

I build AI agents that automate the manual work in sales and outreach.

## Projects

### 01 — AI GTM Research and Outreach Agent
A fully automated sales pipeline. Takes a company name, researches it with Groq AI, finds the founder email, sends personalized cold outreach, tracks replies, and follows up. Zero human input after setup.

**Stack:** n8n, Groq API, Llama 3.1, Gmail, Google Sheets  
**Live:** [vinayakgavimath.github.io/gtm-research-agent](https://vinayakgavimath.github.io/gtm-research-agent)

---

### 02 — Founder Signal Tracker
Monitors 10 founders on Twitter every 6 hours. Extracts the core belief behind each tweet using Groq AI. Generates a signal-based cold email opening line automatically.

**Stack:** Apify, n8n, Groq AI, Llama 3.1, Google Sheets  
**Live:** [vinayakgavimath.github.io/founder-signal-tracker](https://vinayakgavimath.github.io/founder-signal-tracker)
