The Problem

Personalized outreach needs real signal

A GTM engineer wants to send cold outreach that actually lands. To do that they need to know what the founder is thinking about right now. So they open Twitter, scroll through tweets, figure out what's interesting, then write an opening line based on that.

15 minutes per founder. 10 founders. 2.5 hours gone. Every week. Work that repeats forever and is completely automatable.

15m Manual research per founder
2.5h Weekly for 10 founders
6h Automated refresh cycle
$0 Monthly cost
How It Works

Four nodes. End to end.

Schedule Trigger fires every 6 hours. HTTP Request pulls latest tweets from Apify. AI Agent sends each tweet to Groq and extracts insight and outreach angle. Google Sheets logs everything.

The Hard Part

Twitter blocked free API access halfway through.

Set up Twitter developer account

Got the keys. Bearer token. Everything ready. Built the HTTP Request node in n8n.

Executed the first API call

"Resource not found." Spent 30 minutes debugging auth, URL, headers. Everything was correct.

Found the real problem

Twitter's free tier doesn't allow reading tweets. The endpoint requires Basic tier at $200/month.

Tried Nitter RSS

Most public Nitter instances are dead. Twitter killed them all.

Switched to Apify

$0.20 and 6 seconds later, 5 real tweets from Naval were flowing into n8n. Full pipeline working end to end.

The detour is part of the build. Most people stop at "resource not found." Finding the workaround is the actual GTM engineering skill.

Prompt

What I send to Groq

The prompt extracts two things from every tweet: the core belief behind it, and a personalized cold email opening line that uses that belief as context without explicitly mentioning the tweet.

// Prompt sent to Groq AI Agent for each tweet

You are a GTM assistant. Analyze this tweet and return two things:

1. Core Insight: What is the main idea or belief this founder
   is expressing in one sentence.

2. Outreach Angle: Write a personalized cold email opening line
   (max 2 sentences) that references this specific tweet naturally.
   Don't mention you saw their tweet. Just use the idea as context.

What I Learned

The AI can extract the insight. You still have to judge it.

A tweet about election security generates a completely different outreach angle than one about agent-first software. Groq handles the extraction correctly. But deciding whether that angle is worth acting on is still a human call.

That judgment is the GTM skill. The automation just removes the 15 minutes of manual work that came before it.

Automation doesn't replace thinking. It clears the space so thinking is the only thing left to do.
